# dac8.org

Kampagnenwebsite der Bitcoin-Austria-Initiative gegen die anlasslose
Krypto-Datenerfassung durch DAC8 und das österreichische
Krypto-Meldepflichtgesetz.

Die öffentliche Website ist vorerst deutsch. Der Individualantrag ist als
„in Vorbereitung“ gekennzeichnet, bis ein Einreichungsdatum und eine
Geschäftszahl bestätigt sind.

## Entwicklung

```sh
pnpm install
pnpm dev
pnpm build
```

Die zu Recherchezwecken gesicherte dac8.com-Website liegt unter `export/` und
bleibt gitignored. Sie ist keine öffentliche Quelle der neuen Website.
